# PropBench documentation

PropBench is a desktop workbench for thermophysical property research: import measurements, check them against
published data, fit and validate models with stated uncertainty, and export figures, reports and models.

- **Getting started:** [Installation and first project](getting-started.md)
- **Concepts:** [How a study works](concepts.md)
- **Extending:** [Components, plug-ins and contributing](contributing.md)
- **Design and architecture:** see `README.md` in the repository root (§0 integration map, §4 architecture).
