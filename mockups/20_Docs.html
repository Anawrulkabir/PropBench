Your first project: viscosity of CF₃I

This tutorial follows one complete study, from a downloaded table to a validated model and a journal figure. It takes about 20 minutes and uses the example data shipped with PropBench.

1. Create the project

Choose File › New project. In the wizard, pick Fit a model to my measurements. The wizard lists the components this task needs and downloads any that are missing.

2. Import the data

Choose Data › Import and open Viscosity_CF3I_TUHIN_20240327.xlsx. Map each column to a quantity and unit: pressure in MPa, temperature in K, viscosity in μPa·s, the expanded uncertainty in %. Record the source DOI so it travels with the data.

3. Check the data

The data check converts units, compares each phase with the equation of state and looks for duplicates. It also reports that the 2024 and 1999 datasets overlap at 333–338 K, and suggests a consistency study.

4. Set up and run the study

Select the models to compare, the validation scheme (leave one state out) and the physics checks. Then lock the selection rule and press Run all.
Lock the rule first. Choose and lock the model-selection rule before fitting. Changing it afterwards starts a new study, so the choice of model cannot be tuned to the results.

5. Read the results

The selected model, ECS ψ(δ) + k, predicts unseen states within 0.54 % (liquid) and 0.49 % (vapour), with no physics violations. Rejected models are listed with the reason.

6. Do the same from a script

Everything in the interface is also available from Python, in the project's own environment:
import propbench as pb

proj  = pb.open("CF3I viscosity.pbp")
model = pb.models.ECS(reference="R134a", shape="linear", dilute_gas_factor=True)
study = pb.validate(model, proj.datasets["Tuhin 2024"], scheme="loso", seed=2026)
print(study.summary())
