# CF3I viscosity test data — sources

* `tuhin2024_liquid` / `tuhin2024_vapor`: A.R. Tuhin, M. Morshed, K. Kariya, A. Miyara, Experimental investigation and
  empirical models of viscosity of trifluoroiodomethane (CF3I), Int. J. Thermophys. 45 (2024) 41,
  https://doi.org/10.1007/s10765-024-03332-4 — Tables 2 and 3 (45 points). Expanded uncertainty (k = 2): 2.22 %
  liquid, 2.32 % vapour; u(T) = 0.02 K; u(p) = 0.004 MPa (liquid), 0.003 MPa (vapour).
* `duan1999_satliq`: Y.-Y. Duan, L. Shi, L.-Z. Han, M.-S. Zhu, Viscosity of saturated liquid trifluoroiodomethane
  from 253 to 338 K, Fluid Phase Equilib. 162 (1999) 303-312, https://doi.org/10.1016/S0378-3812(99)00216-2
  (18 points). Uncertainty no more than 3 %. Pressures not reported (saturated liquid): the tests take the saturation
  state (pressure and liquid density) from the reference equation of state of CF3I (Lemmon & Span, as implemented in
  CoolProp) and use 3 % as the expanded (k = 2) uncertainty.

Published measurement values, used here as test data with citation. The laboratory Excel file is not part of the
repository.
